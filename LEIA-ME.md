# Mini app Leonardo Soares

Como publicar no GitHub Pages:

1. Crie um repositório público no GitHub (ex.: `leonardo-soares`).
2. Envie TODO o conteúdo desta pasta para a raiz do repositório (index.html, manifest.json, sw.js, .nojekyll e a pasta img).
3. No repositório, vá em Settings > Pages, em "Source" escolha "Deploy from a branch", branch `main`, pasta `/ (root)` e salve.
4. Em 1 a 2 minutos o app estará em `https://SEU-USUARIO.github.io/leonardo-soares/`.

Para a cliente ter o ícone na tela do celular:
- Android (Chrome): menu ⋮ > "Instalar app" ou "Adicionar à tela inicial".
- iPhone (Safari): botão Compartilhar > "Adicionar à Tela de Início".

Ao atualizar fotos ou textos, aumente o número da versão em `leonardo-soares-v2` (por exemplo para `-v3`) no arquivo sw.js para os celulares baixarem a versão nova.
